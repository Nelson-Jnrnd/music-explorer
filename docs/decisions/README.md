# Durable decisions

Store consequential owner-approved or cross-component decisions that future agents must honor. Use `DEC-NNN-short-slug.md` and `templates/DECISION.md`; include question, accepted answer, rationale if known, date, status, affected artifact(s), and source issue/PR. Update the canonical product/design document too. Do not create an entry for routine local code choices or copy full chat transcripts.
