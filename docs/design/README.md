# Design documentation

Put the project's art direction (`ART_DIRECTION.md`, from `templates/ART_DIRECTION.md`), design tokens and visual identity here once the Product Owner has decided them. `PROJECT.md` records the status of the Voice and visual identity decision; this folder holds the detail. Generated and drawn asset work follows `governance/GENERATED_ASSETS.md`, with recipes, run logs, raw outputs and selection records stored next to the assets.
